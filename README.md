Bienvenido al repositorio de mi página web personal. Aquí presento mi portafolio y mi "Programa de Desarrollo de MVP", diseñado específicamente para ayudar a Startups y PyMEs a materializar sus ideas tecnológicas.

##  Sobre Mí
Mi propuesta de valor es simple: **De la idea al prototipo funcional. Sin lidiar con múltiples freelancers.** Actúo como una "Ventanilla Única" (One-Stop Shop) para el desarrollo de Hardware e IoT, cubriendo:
* **Fase 1:** Arquitectura, selección de componentes y diseño de esquemáticos (Altium).
* **Fase 2:** Ruteo de PCB, desarrollo de Firmware (ATMEGA, ESP32, STM32) y diseño mecánico 3D (Fusion 360).
* **Fase 3:** Ensamblaje, algoritmos de control (MATLAB) y entrega de archivos listos para manufactura.

##  Sobre este Proyecto
Este sitio web ha sido desarrollado como una "One-Page" ágil y de carga rápida para mostrar mis proyectos estrella (control de motores DC, placas STM32 y entornos modulares).
